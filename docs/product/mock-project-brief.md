# Activated Mock Project Brief

## Purpose

This repository is a mock product implementation used to validate rollout, governance, and delivery practices with the Activate framework installed.

## Product Scenario

Activated tracks digital service opportunities for cross-functional teams working with federal agencies.

## Mock Objectives

- Demonstrate framework-first repository setup using AGENTS, instructions, prompts, skills, and agent definitions
- Exercise a small but runnable service that can be reviewed and tested
- Provide a baseline for future prompts, ADRs, and quality-gate automation

## Current Scope

- Node HTTP API with read/create endpoints for opportunities
- Unit tests using Node built-in test runner
- Framework assets installed under .github for day-to-day AI-assisted development
